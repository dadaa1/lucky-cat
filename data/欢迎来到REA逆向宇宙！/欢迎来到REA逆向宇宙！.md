REA 创建者刚刚发布了 20 个 GitHub 仓库，用来构建一个他X的逆向工程工作室：

### ［01］ 分析核心

-    **REA** ：一个能接入所有工具的单一 MCP  
    [https://github.com/morluto/rea](https://github.com/morluto/rea)
-    **Ghidra** ：免费反编译器  
    [https://github.com/NationalSecurityAgency/ghidra](https://github.com/NationalSecurityAgency/ghidra)
-    **GhidraMCP** ：让你的 Agent 驱动 Ghidra  
    [https://github.com/LaurieWired/GhidraMCP](https://github.com/LaurieWired/GhidraMCP)
-    **ida-pro-mcp** ：把你的 Agent 接入 IDA Pro  
    [https://github.com/mrexodia/ida\-pro-mcp](https://github.com/mrexodia/ida-pro-mcp)

### ［02］ 移动端与应用

-    **jadx** ：把 Android APK 还原成 Java  
    [https://github.com/skylot/jadx](https://github.com/skylot/jadx)
-    **Apktool** ：拆解并重新打包 APK  
    [https://github.com/iBotPeaches/Apktool](https://github.com/iBotPeaches/Apktool)
-    **Frida** ：在应用运行时进行 Hook  
    [https://github.com/frida/frida](https://github.com/frida/frida)
-    **ILSpy** ：反编译 .NET  
    [https://github.com/icsharpcode/ILSpy](https://github.com/icsharpcode/ILSpy)

### ［03］ 二进制与底层

-    **radare2** ：运行在终端里的逆向工程框架  
    [https://github.com/radareorg/radare2](https://github.com/radareorg/radare2)
-    **x64dbg** ：Windows 调试器  
    [https://github.com/x64dbg/x64dbg](https://github.com/x64dbg/x64dbg)
-    **ImHex** ：带自有模式语言的十六进制编辑器  
    [https://github.com/WerWolv/ImHex](https://github.com/WerWolv/ImHex)
-    **angr** ：符号执行引擎  
    [https://github.com/angr/angr](https://github.com/angr/angr)

### ［04］ 网络与运行

-    **mitmproxy** ：中间人代理，读取流量  
    [https://github.com/mitmproxy/mitmproxy](https://github.com/mitmproxy/mitmproxy)
-    **dnSpy** ：调试并编辑 .NET 应用  
    [https://github.com/dnSpy/dnSpy](https://github.com/dnSpy/dnSpy)  
    （活跃维护版本：[https://github.com/dnSpyEx/dnSpy）](https://github.com/dnSpyEx/dnSpy%EF%BC%89)
-    **rizin** ：radare2 的分支  
    [https://github.com/rizinorg/rizin](https://github.com/rizinorg/rizin)
-    **raddebugger** ：来自 Epic Games 的调试器  
    [https://github.com/EpicGamesExt/raddebugger](https://github.com/EpicGamesExt/raddebugger)

### ［05］ 重建与验证

-    **awesome-ai-reverse-engineering** ：122 个仓库，每个都经过评级  
    [https://github.com/zhuyansen/awesome-ai-reverse-engineering](https://github.com/zhuyansen/awesome-ai-reverse-engineering)
-    **awesome-reverse-engineering** ：由 REA 作者精选整理  
    [https://github.com/morluto/awesome-reverse-engineering](https://github.com/morluto/awesome-reverse-engineering)
-    **REA workflows** ：随 REA 自带的现成调查提示词
-    **clean-room loop** ：SPEC.md、预言机与检查，直到匹配为止
